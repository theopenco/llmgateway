## Freshness provenance and maintenance

- Fumadocs last-modified exports are compiled from a checked-in content-hash/date manifest. Sitemap, article schema, and visible Last updated use the same value.
- Authored pages use their Git content history. Generated API pages are initially dated from gateway source history; unchanged content hashes retain their dates across subsequent builds.
- Docker excludes Git. Builds without full history validate the snapshot rather than fabricating deployment timestamps. Changed content with no trustworthy snapshot fails with a refresh instruction. The no-Git fixture validated all 165 source documents.
- After changing documentation, run `pnpm --filter docs gen-docs` from the repository root in a full-history checkout and commit `apps/docs/lib/content-modified.json`.
- Set an article author only when known. The roundup credits its verified public contributor; legacy posts retain Organization attribution instead of invented human authors. Update the explicit date when the article is genuinely edited.
