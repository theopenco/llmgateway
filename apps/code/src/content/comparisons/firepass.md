## Availability matters before price

Fireworks’ current [Fire Pass documentation](https://docs.fireworks.ai/firepass) says new subscriptions are closed. Existing users and promo recipients can still manage access. It does not publish a current generally available subscription price, so historical launch prices are not a useful checkout comparison.

## Covered routes and client support

An active pass covers the selected open-weight routes enabled for that account, subject to limits. The full Fireworks catalog requires standard API access and separate token billing. FireConnect supports several coding clients, but Fire Pass keys do not currently support the Responses API used by Codex CLI and ChatGPT desktop.

Fire Pass is intended for personal, non-production agentic coding, and keys must not be shared. **Keep Fire Pass** if you already have access and its permitted workflow meets your needs. **Choose DevPass** if you need a plan you can subscribe to now and a model allowance across compatible coding tools. DevPass is also a single-developer subscription, not a shared team key.

## DevPass pricing and limits

DevPass costs **$29/month for Lite, $79 for Pro, or $179 for Max**, for one developer. As of September 27, these plans include $87, $237, and $537 of monthly model usage respectively, with separate premium weekly fair-use limits. Optional pay-as-you-go overflow costs extra.

**Plan changes start October 15, 2026:** new subscriptions begin at 2× the plan price in monthly usage; existing subscriptions move to 2× at their first renewal on or after that date. Daily caps, tighter premium weekly caps, and revised Reset Pass benefits take effect October 15, including within existing billing cycles. Read the [plan-change terms](/legal/terms#october-2026-plan-changes) before subscribing.

Compare the live [coding catalog](/coding-models) and [plan details](/pricing). Client support depends on the API and custom-endpoint features of the coding tool; a DevPass key does not unlock every feature of a third-party editor.
