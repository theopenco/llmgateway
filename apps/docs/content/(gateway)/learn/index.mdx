The LLM Gateway dashboard gives you full control over your LLM API usage, costs, and configuration. This section walks you through every LLM Gateway dashboard page. DevPass, Lounge, and Airside each have their own knowledge base: pick the product from the menu at the top of the sidebar, or start at [DevPass](/devpass), [Lounge](/lounge), or [Airside](/airside).

## Switch products

Open the product menu at the top of the dashboard sidebar to switch between **LLM Gateway**, **DevPass**, **Airside**, and **Lounge**. The checkmark shows your current product. On mobile, open the sidebar first; with a collapsed sidebar, select the LLM Gateway icon.

Switching products opens that product's workspace. It does not transfer API keys, credits, or subscriptions between products. Use the organization selector below the product menu to switch organizations within LLM Gateway.
