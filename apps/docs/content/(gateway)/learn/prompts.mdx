The Prompts page stores your project's prompt templates. Edit a prompt, save it as a new version, and deploy it; requests that reference the prompt pick up the change immediately.

## Creating a prompt

Click **New prompt**, give it a **Name** (letters, numbers, dots, dashes, and underscores), an optional **Default model** and **Description**, and write its **Messages**. Use `{{variable}}` for values each request supplies; they appear under **Variables** as you type. Click **Create prompt**. Version 1 goes live right away.

## Editing and deploying

Select a prompt on the left to open it.

| Section                               | What it does                                                                                   |
| ------------------------------------- | ---------------------------------------------------------------------------------------------- |
| **Messages**                          | The template, prefilled from the production version                                            |
| **Default model**                     | Used when a request does not set `model`                                                       |
| **Change note**                       | Short description stored with the version                                                      |
| **Deploy to production after saving** | When checked, **Save new version** also makes it the production version                        |
| **Versions**                          | Every version, newest first. **Deploy** makes an older or newer version the production version |
| **Use it**                            | A copyable request that calls the prompt                                                       |

<Callout type="info">
	Versions never change after they are saved. Roll back by deploying an earlier
	version.
</Callout>

Project admins can create and change prompts. Reference a prompt from any request with `"prompt": { "id": "<name>" }`; see [Prompt management](/features/prompt-management) for the request format and errors.
