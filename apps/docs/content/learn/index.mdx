The LLM Gateway dashboard gives you full control over your LLM API usage, costs, and configuration. This section walks you through every page in the platform, grouped by product.

## AI Gateway

Configure how requests flow through the gateway — keys, safety rules, and programmatic provisioning:

- [**API Keys**](/learn/api-keys) — Create and manage your API keys, plus per-key statistics
- [**Provider Keys**](/learn/provider-keys) — Bring your own provider API keys
- [**Models**](/learn/models) — Browse catalog and custom models with compliance eligibility
- [**Preferences**](/learn/preferences) — Project-level settings like caching and mode
- [**Guardrails**](/learn/guardrails) — Content safety rules and filters
- [**Security Events**](/learn/security-events) — Monitor guardrail violations
- [**Payments SDK**](/learn/sdk-settings) — Embed end-user payments and credit purchases into your own app
- [**Dynamic Routes**](/learn/dynamic-routes) — Named, versioned routing flows with conditions and A/B splits (Enterprise)
- [**Master Keys**](/learn/master-keys) — Provision projects and API keys programmatically (Enterprise)

## Observability

Monitor usage, spend, errors, and performance across every request:

- [**Dashboard**](/learn/dashboard) — Overview of your usage, costs, and performance
- [**Activity**](/learn/activity) — Detailed logs of every API request
- [**Agents Monitoring**](/learn/agents) — Cost, tokens, and sessions per coding agent
- [**Model Usage**](/learn/model-usage) — Usage breakdown by model
- [**Usage & Metrics**](/learn/usage-metrics) — Requests, errors, cache rates, and cost trends
- [**Analytics**](/learn/analytics) — Cost, requests, and tokens broken down by model
- [**Organization Analytics**](/learn/org-analytics) — Cost and usage rolled up across every project
- [**Member Analytics**](/learn/member-analytics) — Per-member cost and usage breakdowns (Enterprise)
- [**Audit Logs**](/learn/audit-logs) — Complete history of organization actions

## DevPass

Flat-price dev plans for AI coding tools:

- [**Coding Agents**](/learn/coding-agents) — See which coding tools your DevPass key is used with
- [**Model Categories & Fair Use**](/learn/model-categories) — How models are categorized and premium fair-use caps
- [**Reset Passes**](/learn/reset-passes) — Instantly restore the DevPass weekly premium allowance
- [**Pay-As-You-Go Overflow**](/learn/payg-overflow) — Keep coding past the monthly allowance with an opt-in credits balance

## Lounge

The members' lounge for AI — chat, media studios, and memberships:

- [**Lounge Chat**](/learn/playground) — Chat with 200+ models in one interface
- [**Group Chat**](/learn/playground-group) — Watch multiple models discuss and collaborate on your prompt
- [**Image Studio**](/learn/playground-image) — Generate images using AI models
- [**Video Studio**](/learn/playground-video) — Generate videos using AI models
- [**Audio Studio**](/learn/playground-audio) — Generate speech from text using AI voices
- [**Voice Calls**](/learn/playground-realtime) — Have a live speech-to-speech conversation with a model
- [**Lounge Memberships**](/learn/chat-plans) — Monthly membership plans for the Lounge chat app

## Airside

The self-serve console for model providers ("carriers"):

- [**Airside Fleet**](/learn/airside-fleet) — List models, file tariffs, and manage your carrier's fleet
