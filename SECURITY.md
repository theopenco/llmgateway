# Security Policy

## Reporting a Vulnerability

Please report security issues privately. Do not open public issues for them.

- **Preferred:** [GitHub private vulnerability reporting](https://github.com/theopenco/llmgateway/security/advisories/new)
- **Alternative:** email [contact@llmgateway.io](mailto:contact@llmgateway.io)

Include the affected endpoint or component, steps to reproduce, and the impact. We'll look into it promptly.

These contacts are also published at [`/.well-known/security.txt`](https://llmgateway.io/.well-known/security.txt) ([RFC 9116](https://www.rfc-editor.org/rfc/rfc9116)).

## Guidelines

- Test only against accounts, API keys and data you own.
- Do not access, modify or retain other users' data. If you encounter it, stop and report it.
- No denial of service, load testing, spam or social engineering.
- Give us reasonable time to fix an issue before disclosing it publicly.
